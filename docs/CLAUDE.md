# 수원시 도서관 웹사이트 개선

도서 검색·상세 화면에서 이용자가 대출 가능 여부를 정확하고 쉽게 판단하도록 개선한다.
요구사항의 원본은 [PRD.md](PRD.md)이며, 이 문서와 내용이 다르면 PRD를 따른다.

## 사용자

### 만드는 사람

- 이 서비스는 코딩 초보자가 만든다.
- 설명은 쉬운 말로 하고, 전문 용어를 쓸 때는 뜻을 함께 풀어 쓴다.
- 모르거나 애매한 부분은 추측하지 말고 먼저 질문한다.

### 서비스 이용자

도서 검색, 대출·반납 상태 확인, 예약을 이용하는 수원시민 전체를 대상으로 한다.

- **고령·적록색약 이용자:** 대출 가능 여부를 한눈에 구별하고 안심하고 도서관을 방문하기를 기대한다.
- **스크린 리더 이용자:** 음성만으로 상태를 정확히 파악하고 혼자서 예약까지 완료하기를 기대한다.

## 기술 스택 (변경 금지)

프로젝트 초기화 때 구성한 아래 기술만 사용한다. 변경하거나 라이브러리를 추가해야 할 것 같으면 먼저 질문한다.

- React 19 (JavaScript, JSX)
- Vite 8
- oxlint

| 명령어 | 용도 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 |
| `npm run lint` | 코드 규칙 검사 |
| `npm run preview` | 빌드 결과 미리보기 |

## 디자인 규칙

디자인은 추후 피그마 MCP를 통해 구현한다. 피그마 디자인이 제공되기 전에는 색상, 형태, 레이아웃을 임의로 정하지 않는다.

### 접근성

KWCAG 2.2와 디지털 정부서비스 UI/UX 가이드라인을 준수한다.

- 색상은 보조 수단으로만 사용한다. 대출 상태는 텍스트 라벨과 테두리로 구별한다.
- 서체 크기는 16px 이상, 명도 대비는 4.5:1 이상, 터치 타겟은 44px로 한다.
- 표에는 `<caption>`, `<th>`, `<td>`를 적용한다.
- 상태 메시지에는 `aria-live="assertive"`를 적용한다.
- 상태 배지는 스크린 리더에서 "대출 가능, 배지" 또는 "대출중, 반납예정일 OOOO년 O월 O일" 형태로 낭독되도록 한다.

### 반응형

- 브레이크포인트는 모바일 ~767px, 태블릿 768px ~ 1439px, 데스크탑 1440px ~ 이다. 모바일은 360px 이상을 지원하고 4컬럼 그리드를 사용한다.
- 모바일 우선으로 구현한다. 기본 스타일은 모바일 기준으로 작성하고, min-width 미디어쿼리로 확장한다.
- 1440px 이상에서는 콘텐츠 최대 폭을 rem 단위로 제한하고 가운데 정렬하며, 배경은 화면 전체를 채운다.
- 사이즈별 상세 반응형 디자인은 구현 단계에서 PRD 7.4에 추가한다. 그 전에는 임의로 구조를 가정하지 않는다.

### 단위

- 레이아웃에는 %, rem을 사용하고 고정 px 너비는 지양한다. em은 letter-spacing에만 사용한다.
- px은 border/outline 두께, box-shadow, border-radius, 미디어쿼리 브레이크포인트 값에만 허용한다.
- 서체 16px은 `1rem`, 터치 타겟 44px은 `2.75rem`으로 작성한다.

### 용어

내부 행정 용어 대신 아래 표현을 쓰고, 도움말(툴팁·인라인 설명)을 함께 제공한다.

| 사용하지 않음 | 사용 |
|---|---|
| 비치중 | 대출 가능 (서가 비치) |
| 예약자수 0/2 | 예약 가능 인원 2명 중 0명 대기 |

## 서비스 구조

### 핵심 흐름

```
[메인] 도서 검색
  → [검색 결과 목록] 필터 적용, 상태 배지·반납예정일 확인
  → [도서 상세] 소장도서관 표, 서가 위치 배치도 확인
  → 대출 가능: 도서관 방문 / 대출 중: [예약하기]
  → [예약 완료 모달] 대기 순번·예상 수령일 확인
```

### 화면별 기능

**메인**
- FR-01: 로그인 후 상단 퀵 영역에 [내 대출현황/마이페이지] 버튼을 배치한다.
- FR-02: 퀵 아이콘 바의 최우선 위치에 [대출·반납·연장 조회]를 배치한다.

**검색 결과 목록**
- FR-03: [대출가능 도서만 보기] 토글과 도서관 선택 스코프를 제공한다.
- FR-04: [대출가능]/[대출중] 배지를 텍스트 라벨과 테두리로 표시하고 범례를 제공한다. 배지는 카드 내에서 최우선으로 인지되도록 배치한다.
- FR-05: 대출중 배지 바로 옆에 `반납예정일: YYYY-MM-DD`를 표시한다.
- FR-06: 용어를 개선하고 툴팁을 제공한다.
- FR-07: 카드 하단에 [예약하기], [관심도서], [책배달] 버튼을 노출한다.
- FR-08: 배지에 대체 텍스트를 제공한다.

**도서 상세**
- FR-09: 상단 대출 상태와 하단 소장 목록을 항상 일치시킨다.
- FR-10: 소장도서관, 청구기호, 대출상태, 반납일을 구조화된 표로 출력한다.
- FR-11: 청구기호 옆 [서가 위치 배치도 보기] 버튼으로 팝업을 연다.
- FR-12: 소장도서관 표 하단에 용어 설명 패널을 상시 노출한다.
- FR-13: 책 소개·ISBN 데이터가 없으면 해당 컨테이너를 노출하지 않는다.

**대출 예약**
- FR-14: 예약 완료 모달에 내 대기 순번과 예상 수령일을 표시한다.
- FR-15: 완료 피드백을 시각 사용자와 스크린 리더 사용자 모두에게 제공한다.

### 개선 우선순위

- **P0:** 대출 상태 인지성·포용적 정보 전달, 대출 상태-소장 정보 일치
- **P1:** 마이페이지 진입점·퀵 메뉴, 검색 필터·예약 및 책배달 연결
- **P2:** UI 컴포넌트 일관성, 예외 상태 검증

## 안전 규칙

### 먼저 질문해야 하는 작업

- 파일이나 폴더 삭제, 덮어쓰기처럼 되돌리기 어려운 작업
- 기술 스택 변경, 라이브러리 추가
- 요청 범위를 벗어나는 수정
- 외부 서비스로 데이터를 보내거나 공개하는 작업

### 임의로 정하지 않는 항목

PRD에서 "추가 확인 필요" 또는 "다음 단계에서 확정 예정"으로 표시한 항목이다. 구현 전에 질문한다.

- 색상 코드, 배지 형태·크기, 아이콘 세부 규격
- 소장도서관 정보가 없을 때의 대체 문구 (공란으로 두지 않는다)
- 예약 실패, 예약 한도 초과, 로그인 만료, 네트워크 오류, 검색 결과 0건의 처리와 메시지
- 반납예정일 미확정·연체 중 도서의 표시 방식
- 예약 한도, 연장 가능 횟수, 예상 수령일 산정 기준
- 그 밖의 용어 점검과 표준 용어집

### 작업 후 확인

- 코드를 수정한 뒤에는 `npm run lint`와 `npm run build`를 실행하고 결과를 그대로 알린다.
- 확인하지 못한 내용은 확인하지 못했다고 알린다.
