# 디자인 토큰

이 문서는 색, 글꼴, 텍스트 스타일, 컴포넌트 치수를 값으로 정리한 것이다. 다른 문서나 파일 없이 이 문서만으로 읽을 수 있다.

- **토큰:** 디자인 값(색, 크기 등)에 이름을 붙여 둔 것
- **원칙:** 디자인 원본에 정의된 값만 실었다. 정의되지 않은 값은 새로 만들지 않고 맨 아래 "정의되지 않은 값"에 적었다.
- **"Figma에 없음" 표시:** 디자인 원본(Figma)에는 변수·스타일로 정의되지 않았지만, 개발 토큰에는 있는 값이다.

## 단위 규칙

- 크기는 px로 적고, 괄호 안에 rem 값을 함께 적었다. rem은 px를 16으로 나눈 값이며 반올림하지 않았다. 예: 18px (1.125rem)
- 자간은 Figma 퍼센트(%) 값과 em 값을 함께 적었다. em은 %를 100으로 나눈 값이다. 예: -2% (-0.02em)
- 라운드, 테두리 두께, 그림자는 px로만 적었다.

## 반응형 기준

값은 화면 너비에 따라 3가지 모드로 나뉜다. 모드 사이에 차이가 없는 값은 한 번만 적었다.

| 모드 | 기준 화면 너비 | 적용 범위 |
|---|---|---|
| mobile | 402px | 767px 이하 |
| tablet | 768px | 768px ~ 1439px |
| desktop | 1440px | 1440px 이상 |

## 텍스트 스타일

6개 스타일 모두 글꼴은 Pretendard이다. tablet은 mobile과 같은 크기와 행간을 쓴다.

| 스타일 | 굵기 | mobile·tablet 크기 / 행간 | desktop 크기 / 행간 | 자간 |
|---|---|---|---|---|
| hero | Pretendard 800 | 32px (2rem) / 38px | 48px (3rem) / 57px | 0% (0em) |
| h1 | Pretendard 700 | 24px (1.5rem) / 29px | 32px (2rem) / 38px | -2% (-0.02em) |
| h2 | Pretendard 600 | 20px (1.25rem) / 24px | 28px (1.75rem) / 33px | -2% (-0.02em) |
| h3 | Pretendard 600 | 18px (1.125rem) / 21px | 22px (1.375rem) / 26px | -2% (-0.02em) |
| body | Pretendard 400 | 16px (1rem) / 19px | 20px (1.25rem) / 24px | -2% (-0.02em) |
| small | Pretendard 300 | 16px (1rem) / 19px | 20px (1.25rem) / 24px | -2% (-0.02em) |

행간은 Pretendard 기본 행간(글자 크기의 약 1.17~1.21배)이 실제로 그려지는 높이를 px로 고정한 값이다.

### 가장 큰 글자와 가장 작은 글자

| 구분 | 스타일 | mobile·tablet | desktop |
|---|---|---|---|
| 가장 큰 글자 | hero | Pretendard 800, 32px (2rem), 행간 38px | Pretendard 800, 48px (3rem), 행간 57px |
| 가장 작은 글자 | body | Pretendard 400, 16px (1rem), 행간 19px | Pretendard 400, 20px (1.25rem), 행간 24px |

- 가장 작은 크기는 body와 small이 같고, 굵기로만 구분한다.

## 정의되지 않은 값

디자인 원본과 개발 토큰 어디에도 없는 값이다. 이 문서에 없는 값을 임의로 정하지 말고, 디자인 원본에 먼저 정의한 뒤 쓴다.

| 분류 | 항목 | 현재 상태 |
|---|---|---|
| 치수 | 카드·목록 항목 너비 | 화면 폭에 맞춰 늘어나는 크기라 고정값이 없다. 모바일 시안에서는 370px로 그려져 있다. |
| 치수 | 배지 크기 | 대출 상태 배지의 너비·높이·안쪽 여백이 정의되지 않았다. |

## 확인이 필요한 점

- **성공 색 대비 부족:** status/success(#FF8700)는 흰 배경에서 2.41:1이라 글자 색으로 쓰기에는 기준(4.5:1)에 못 미친다. 글자에 쓸 때는 더 진한 색을 정하거나, 배지 배경색으로만 쓰고 글자는 다른 색을 써야 한다.
- **다크 모드 오류 색:** 팔레트에 밝은 빨강이 없어서 다크 모드의 status/error도 #B3261E를 쓴다. 어두운 배경에서 2.79:1이라 기준에 못 미친다.
- **다크 모드는 초안:** 다크 값은 팔레트를 밝기 반대로 짝지어 만든 초안이다. 로고 글자, 노트 아이콘처럼 쓰임새별 색이 아닌 팔레트 색을 직접 쓰는 부분은 다크 모드에서도 어두운 색으로 남는다.
